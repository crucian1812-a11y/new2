# Присланные паки анимации

Здесь лежат наборы анимации, которые приходили в проект, и результат их
измерения. Файлы оставлены как есть — чтобы никто не проверял их второй раз.

## `BJJ_WOW_*` — «BJJ Mobile Animation Pack v2», 84 клипа

Что обещает: ровно то, чего проекту не хватает. Парная анимация, два скелета
`A_`/`B_` с мixamo-именами костей, и словарь клипов, ложащийся на игру почти
один в один — удержания по позициям (`gr_*`), переходы (`tr_*`), тейкдауны
(`td_*`), сдачи вход/финиш (`sub_*`), реакции (`rx_*`) и 12 связок (`wow_*`).

Что оказалось при измерении (`node bjj/tools/clip-check.mjs <файл>.glb`):

```
скелет:      позвоночник 86 см при ноге 82 см — отношение 1.05;
             у человека и у нашего рига 0.61
плоские:     0 см — в каждом клипе хотя бы одна фигура схлопнута в плоскость
под матом:   медиана 11 см, худшее 22 см
колени:      медиана 22 см — колено заходит за противоположную сторону
             собственного таза
слипание:    ближайшие центры суставов сходятся в 0 см
```

Ни один из 84 клипов не проходит планку, которую уже держат собственные позы
игры (худшее пересечение 8 см в удержании, 21 см в худший момент перехода).

Генератор в метаданных честно называет себя `procedural production-previs
generator`: это раскладка силуэтов под один ракурс шоурила, а не движение.
Картинка из `clip-check --dump` показывает это без чисел: спереди нижний боец —
одна горизонтальная линия, у верхнего бёдра перекрещены, ступни под матом.

Отдельно: клипы `gr_*`, ради которых пак и стоило бы брать — это «движение
внутри позиции», названное в HANDOFF настоящим потолком, — двигаются на **4–5 см
кистью** и ничем больше: 10 из 54 каналов. В игре дыхание уже есть.

`BJJ_WOW_Showcase.mp4` — рендер того же самого. В кодеке `mp4v` (MPEG-4 Part 2),
ffmpeg из окружения его не декодирует, но смотреть там нечего: это те же данные.

**Вывод: в игру не идёт.** Импортировать это — заплатить второй раз тот самый
долг, из-за которого в проекте появились измерители: пятнадцать поз, написанных
углами без обратной связи, с телами внутри друг друга.

## Что из этого осталось полезного

Инструменты, которыми пак измерен. Следующий пак судится за пять секунд:

```bash
node bjj/tools/clip-check.mjs пак.glb            # вся батарея по клипам
node bjj/tools/clip-check.mjs пак.glb --all      # каждый клип, не только худшие
node bjj/tools/clip-check.mjs пак.glb --dump out # скелеты: спереди, сбоку, сверху
```

- `tools/glb.mjs` — чтение GLB вместе с анимацией (сэмплер каналов TRS,
  linear/step/cubic).
- `tools/retarget.mjs` — перенос чужой позы на наш скелет по **направлениям**
  костей. Вынесен из `mixamo-pose.mjs` без изменения поведения.
- `tools/clip-check.mjs` — измеритель. Первым делом он проверяет **сам себя**:
  печатает, насколько точно перенос лёг на наш риг. На этом паке — 46 см, и
  поэтому его собственное число «внутри» помечено звёздочкой и не считается
  вердиктом. Приговор выносят три меры, которым чужие пропорции безразличны:
  под матом, плоскость, перекрещенные колени.

Требования к следующему паку, если будете искать: пропорции человека
(позвоночник ≈ 0.6 ноги), фигуры с глубиной, ступни не ниже мата — и парность,
конечно.
