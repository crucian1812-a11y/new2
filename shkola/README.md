# Школа

Домашний генератор уроков для первоклассника. Родитель кидает страницу
учебника или просто пишет тему — получается короткий озвученный урок с
вопросами, который ребёнок проходит сам, тыкая в большие кнопки.

Сделано под конкретного ребёнка: шесть лет, первый класс, читать ещё почти не
умеет. Отсюда всё остальное.

## Как открыть

Двойным щелчком по `index.html`. Сборки нет, сервера нет, зависимостей нет —
один файл, который работает и с флешки, и с рабочего стола.

Демо-уроки («Буква М», «Считаем до 5») лежат внутри файла и играются без
ключа и без интернета. Ключ нужен только чтобы собирать новые.

## Как собрать свой урок

Шестерёнка в правом верхнем углу → экран для родителей.

1. Ключ Anthropic API — берётся на console.anthropic.com. Он хранится в
   `localStorage` этого браузера и никуда больше не уезжает.
2. Тема («Буква Р», «Состав числа 6») **или** файл: PDF, фотография разворота,
   текст. Можно и то и другое — тогда тема уточняет, что взять со страницы.
3. «Что учесть» — куда написать «путает Б и Д» или «любит динозавров».

Один урок — примерно на две-три копейки. Модель `claude-opus-5`, шесть сцен.

## Что внутри

Один файл, разделённый на девять кусков с заголовками. Порядок сверху вниз:
демо-уроки → проверка урока → голос → хранилище → экраны → плеер → сборка
моделью → экран родителя → провода.

**Урок** — это объект: `title`, `icon`, `scenes[]`. Сцена бывает двух видов.
`story` — картинка из эмодзи, крупная надпись и озвучка; ребёнок слушает и
жмёт «Дальше». `quiz` — вопрос и два-три варианта, ровно один верный; за
верный даётся звезда, за неверный — «попробуй ещё разок» и никакого наказания.

**Голос** — Web Speech API. Бесплатно, работает без сети, качество среднее.
Русский голос есть почти в любой системе, но список голосов приезжает
асинхронно, поэтому его приходится ждать (`onvoiceschanged`). Если голоса нет,
приложение об этом честно говорит на экране родителя.

**Сборка** — один вызов Messages API прямо из браузера
(`anthropic-dangerous-direct-browser-access`). Урок приходит не текстом, а
через инструмент `sobrat_urok` со строгой схемой (`strict: true`), поэтому
разбирать ответ регулярками не приходится.

## Проверка

```
node shkola/tools/verify.mjs
```

Секунд десять. Проверяет три вещи по порядку:

1. **Правила урока** — подсовывает заведомо кривые уроки и смотрит, ловит ли
   их проверка. Урок без верного ответа, с двумя верными, с одинаковыми
   вариантами — всё это должно заворачиваться.
2. **Демо-уроки** — проходят ли они собственные правила.
3. **Живой прогон** — открывает страницу в Chromium, кликает урок до конца,
   отвечает верно (верный вариант спрашивает у самого урока, а не угадывает),
   проверяет финальный экран, размер кнопок и молчание консоли.

Правила делятся на **ошибки** и **замечания**. Ошибка заворачивает урок:
плеер такой не сыграет. Замечание («длинная фраза», «трудное слово»,
«картинка рябит») показывается родителю, а решает он. Так сделано нарочно:
жёсткая проверка возрастных правил отбраковывала бы нормальные уроки.

Проверка живёт в самом приложении (`window.SHKOLA.proveritUrok`) и работает во
время сборки, а не только в тестах. Тест её лишь дёргает.

## Чего пока нет

- **Голос посредственный.** Системный синтезатор звучит как автоответчик.
  Живой голос — это отдельный TTS по API, деньги за каждую сцену и возня с
  кэшированием звука. Стоит делать, только если ребёнку зайдёт само занятие.
- **Картинки только из эмодзи.** Рисовать настоящие иллюстрации — генерация
  изображений, время и деньги. Эмодзи внезапно неплохо работают: они крупные,
  узнаваемые и мгновенные.
- **Нет прогресса и повторения.** Звёзды за урок запоминаются, но какая буква
  западает — нет. Если игрушка приживётся, следующий шаг именно этот:
  запоминать промахи и подмешивать их в новые уроки.
- **Один ребёнок, один браузер.** Всё в `localStorage`. Уроки переносятся
  файлом через «Сохранить всё в файл».
